# 🏃‍♀️ Un Día Para Latir — Mapa del Recorrido

Mapa interactivo del circuito urbano del evento **Un Día Para Latir** (3 de octubre, Santa Fe, Argentina).
Muestra los recorridos largo y corto con animación de corredoras que van pintando la ruta en tiempo real, marcadores de puntos clave y control de velocidad por tramo.

---

## ✨ Características

- 🗺️ **Mapa fijo de Santa Fe** sobre OpenStreetMap (sin API key, gratis)
- 🟠 **Ruta Larga** — Gimnasio Kalos → Estación Belgrano → Costanera → Faro → El Molino
- 🟣 **Ruta Corta** — Gimnasio Kalos → Estación Belgrano → El Molino
- 🏃‍♀️ **Corredora animada** que pinta el recorrido a velocidad constante (basada en metros reales, no en cantidad de puntos)
- 👥 **Modo "Ambas rutas"** — dos corredoras corren simultáneamente por cada recorrido
- 📍 **Marcadores** de salida, retornos, hidratación y llegada
- 💧 **Punto de hidratación** sobre el Boulevard Gálvez
- 📱 **Diseño responsive** — funciona en desktop, tablet y móvil
- 🎨 **Interfaz moderna** con glassmorphism y los colores del evento
- ⚡ **Zoom dinámico** que sigue a la corredora durante el recorrido
- 🔄 **Botón de reinicio** sin residuos visuales

## 🛠️ Tecnologías

- **HTML5 + CSS3 + JavaScript vanilla** — sin frameworks ni build step
- **[Leaflet.js 1.9.4](https://leafletjs.com/)** — librería de mapas interactivos
- **[OpenStreetMap](https://www.openstreetmap.org/)** — tiles del mapa base (gratis, sin API key)
- **[Google Fonts — Poppins](https://fonts.google.com/specimen/Poppins)** — tipografía
